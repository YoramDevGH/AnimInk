# Security Policy

## Reporting a vulnerability

Please do not disclose a security or privacy vulnerability in a public issue. Use GitHub's private vulnerability reporting feature on the repository's **Security** tab instead.

Include the affected AnimInk version, impact, reproduction steps, and any suggested mitigation. Avoid attaching personal `.aink` projects or device data.

Preview APKs are provided for testing and are currently signed with a developer debug key. Verify that downloads come from this repository and compare the published SHA-256 checksum when one is provided.
